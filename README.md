# Green Cat

Green Cat is a bilingual Design & Development Studio website built with Next.js, React, and TypeScript.

## Current foundation

This scaffold establishes:

- locale-aware `/en` and `/ru` routes;
- typed dictionaries;
- Green Cat Design System v1.0 tokens and typed UI primitives;
- Tailwind CSS and global styles;
- local font packages for Onest and IBM Plex Mono;
- ESLint, TypeScript, Vitest, and Playwright configuration;
- the approved project folder boundaries;
- responsive Navigation, Hero, and Selected Work sections.

The design-system source of truth is [docs/green-cat-design-system-v1.0.md](docs/green-cat-design-system-v1.0.md).

## Commands

- `npm run dev` — local development
- `npm run build` — production build
- `npm run lint` — ESLint
- `npm run typecheck` — TypeScript
- `npm run test` — unit tests
- `npm run test:e2e` — Playwright tests
- `npm run check` — lint, types, and unit tests
